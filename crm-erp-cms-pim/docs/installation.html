Installation Guide

Step-by-step installation and configuration instructions

System Requirements

Before installing the framework, ensure your system meets the following requirements:

Server Requirements
  • PHP: 7.4 or higher
  • Web Server: Apache 2.4+ or Nginx
  • Database: MySQL 5.7+ / MariaDB 10.2+
  • Memory: 128MB minimum (512MB recommended)
PHP Extensions
  • PDO
  • pdo_mysql
  • mbstring
  • openssl
  • json
  • fileinfo
  • session

Installation Steps

Step 1: Download the Framework

Clone the repository or download the source code:

# Clone via Git
git clone https://github.com/your-org/framework.git

# Or download and extract the ZIP file
unzip framework.zip

Step 2: Configure Web Server

Apache Configuration

Point your web server's document root to the public directory:

<VirtualHost *:80>
    ServerName myapp.local
    DocumentRoot "/path/to/framework/public"
    
    <Directory "/path/to/framework/public">
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
Tip: Make sure mod_rewrite is enabled in Apache for clean URLs to work.

Nginx Configuration

server {
    listen 80;
    server_name myapp.local;
    root /path/to/framework/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.ht {
        deny all;
    }
}

Step 3: Configure Environment

Copy the environment file and configure your settings:

# Copy environment file
cp config/.env.example config/.env

# Edit configuration
nano config/.env

Update the database credentials in config/.env:

# Database Configuration
DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=your_database_name
DB_USERNAME=your_username
DB_PASSWORD=your_password

# Application
APP_NAME="My Application"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://myapp.local

# Security
APP_KEY=your-secret-application-key
Important: Generate a secure APP_KEY for production environments. You can use bin2hex(random_bytes(32)) in PHP.

Step 4: Set Directory Permissions

Set proper permissions for writable directories:

# Linux/Mac
chmod -R 775 storage
chmod -R 775 storage/logs
chmod -R 775 storage/cache
chmod -R 775 storage/uploads
chmod -R 775 storage/sessions

# Ensure web server can write to these directories
chown -R www-data:www-data storage
Security Note: Never make the entire application directory writable. Only storage subdirectories need write permissions.

Step 5: Create Database

Create a new database for your application:

CREATE DATABASE your_database_name CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

Step 6: Run Migrations

Run database migrations to create tables:

# Navigate to project root
cd /path/to/framework

# Run migrations
php cli/migrate.php up

You should see output like:

Running migrations...
✓ 2024_01_01_000001_create_users_table
✓ 2024_01_01_000002_create_roles_table
✓ 2024_01_01_000003_create_permissions_table
...
All migrations completed successfully!

Step 7: Seed Database (Optional)

Populate the database with initial data:

php cli/seed.php run

This will create:

  • Default admin user
  • Basic roles (Admin, Manager, User)
  • Permissions
  • Sample data for testing
Success! Your framework is now installed and ready to use!

Post-Installation Steps

Verify Installation

Access your application in a web browser:

http://myapp.local

You should see the welcome page.

Login to Admin Panel

Default administrator credentials (if you ran seeders):

  • Email: admin@example.com
  • Password: admin123
Security Warning: Change the default admin password immediately after first login!

Clear Cache

If you encounter any issues, try clearing the cache:

php cli/cache.php clear

Troubleshooting

Common Issues

Blank Page / 500 Error

Solution:

  1. Check file permissions on storage directories
  2. Enable error display in config/.env: APP_DEBUG=true
  3. Check storage/logs/app.log for error messages
  4. Verify web server configuration
Database Connection Error

Solution:

  1. Verify database credentials in config/.env
  2. Ensure MySQL/MariaDB service is running
  3. Check if database exists
  4. Verify user has proper permissions
  5. Test connection: mysql -u username -p database_name
404 Errors on Routes

Solution:

  1. Ensure mod_rewrite is enabled (Apache)
  2. Check public/.htaccess file exists
  3. Verify web server AllowOverride All is set
  4. For Nginx, check try_files configuration
Permission Denied Errors

Solution:

  1. Set proper ownership: chown -R www-data:www-data storage
  2. Set permissions: chmod -R 775 storage
  3. Check SELinux settings (if applicable)
