## 📖 Contributing to Documentation

To add new documentation pages:

1. Create HTML file in `/docs` directory
2. Use the standard sidebar navigation (copy from existing pages)
3. Include necessary CSS/JS:
   - Bootstrap 5
   - Font Awesome 6
   - Prism.js for syntax highlighting
   - Custom `assets/css/docs.css`
4. Follow the established structure and styling
5. Add navigation links to all pages
